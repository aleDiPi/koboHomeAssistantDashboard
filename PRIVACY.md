# Informativa sulla privacy / Privacy policy

## Italiano

Questa è un'applicazione per uso personale: una dashboard domestica per
[Home Assistant](https://www.home-assistant.io/), usata solo dal suo proprietario.

- **Quali dati usa:** gli eventi del Google Calendar del proprietario, tramite la
  sua installazione di Home Assistant. La dashboard li legge e li mostra
  soltanto: non crea, non modifica e non cancella eventi.
- **Dove restano:** sui dispositivi del proprietario (il server Home Assistant e
  lo schermo della dashboard).
- **Condivisione:** i dati non vengono venduti, condivisi con terzi, inviati allo
  sviluppatore o usati per pubblicità o profilazione.
- **Revoca:** l'accesso si può revocare in qualsiasi momento da
  [Account Google → Connessioni con terze parti](https://myaccount.google.com/connections)
  o rimuovendo l'integrazione da Home Assistant.
- **Contatti:** aprire una segnalazione in
  [GitHub](https://github.com/aleDiPi/koboHomeAssistantDashboard/issues).

L'uso e il trasferimento delle informazioni ricevute dalle API di Google
rispettano la
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
compresi i requisiti sull'uso limitato (Limited Use).

## English

This is a personal-use application: a home dashboard for
[Home Assistant](https://www.home-assistant.io/), used only by its owner.

- **Data used:** events from the owner's own Google Calendar, through the owner's
  Home Assistant installation. The dashboard only reads and displays them: it
  never creates, changes or deletes events.
- **Where data stays:** on the owner's devices (the Home Assistant server and the
  dashboard screen).
- **Sharing:** data is not sold, shared with third parties, sent to the
  developer, or used for advertising or profiling.
- **Revoking access:** at any time from
  [Google Account → Third-party connections](https://myaccount.google.com/connections),
  or by removing the integration from Home Assistant.
- **Contact:** open an issue on
  [GitHub](https://github.com/aleDiPi/koboHomeAssistantDashboard/issues).

The use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
